# Diseños de registro oficiales del modelo 303

Excel publicados por la AEAT (modelos 303 y 390) en
https://sede.agenciatributaria.gob.es/Sede/ayuda/disenos-registro/modelos-300-399.html

La AEAT solo mantiene publicado el diseño vigente, así que aquí se guarda una copia
de cada versión. `manifest.json` indica desde qué trimestre aplica cada una.

Para añadir un ejercicio nuevo basta con copiar aquí su `.xlsx` y añadir su entrada
al manifiesto (o usar `fiscal diseno instalar`, que lo deja en `FISCAL_DATA_DIR/disenos`).
Ninguna posición está escrita a mano en el código: todo se lee del Excel.
